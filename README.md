# 浮光歌词 (LyricsShow)

> **极简 · 实用 · 小巧（APK 仅 1.6MB）的 Android 实时歌词小软件**

---

## 🌟 核心特色

1. **体积极小**：最终 Release 安装包仅 **1.6MB**，零第三方臃肿框架，纯原生轻量高效。
2. **功能优先可用**：
   - **三种浮窗模式自由切换**：
     - **一行模式**：轻量胶囊，置顶单行歌词，可拖动、展开快捷控制条。
     - **全屏/很大模式**：悬浮大视窗，多行滚动歌词，支持歌曲进度条拖动与控制，兼顾悬浮与沉浸。
     - **小圈圈模式**：48dp 小圆球浮标，不占屏幕空间，点击即可快速展开。
   - **系统级媒体监听**：自动监听网易云音乐、QQ音乐、酷狗、Spotify、Apple Music 等任意播放器的歌曲进度与曲目信息。
   - **多源在线歌词智能搜索**：内置酷狗、网易云、LRCLIB 多引擎梯级检索与清洗，支持手动搜索换词与本地高速缓存。
   - **防误触锁定与浮动解锁标**：锁定后全穿透点击（不影响游戏与日常操作），并伴随可移动解锁标，轻点随时解除锁定。
   - **时间轴微调**：支持 `±0.5s` 歌词快慢微调与一键复位，彻底解决音画/歌词不同步问题。
   - **内置即刻测试播放**：自带《晴天》示例曲目与同步时间轴，无需打开第三方音乐 App，安装即可 1 秒测试验证。

## 📦 APK 安装包位置

- **极简 Release 安装包 (推荐，仅 1.6MB)**：
  `app/build/outputs/apk/release/app-release.apk`

  `app/build/outputs/apk/debug/app-debug.apk`

### 快速安装到连接的手机：
```bash
adb install -r app/build/outputs/apk/release/app-release.apk
```

## 🚀 使用指南

1. **初次打开**：
   - 界面上方会清晰展示两项必要权限状态：
     - **【悬浮窗权限】**：点击“去授权”，在系统设置中开启“允许显示在其他应用上”。
     - **【通知监听权限】**：点击“去授权”，勾选允许“浮光歌词”监听通知（用于获取当前播放进度与曲目）。
2. **即刻测试**：
   - 点击主界面上的 **【开启桌面悬浮歌词】**，屏幕上方立即弹出胶囊悬浮歌词。
   - 点击 **【▶ 立即测试播放 (周杰伦-晴天)】**，歌词将立即在悬浮窗和主界面实时滚动同步！
3. **日常跟唱**：
   - 打开网易云音乐或 QQ音乐等任意音乐软件播放歌曲，浮光歌词将自动获取歌曲名并匹配同步歌词。
   - 点击桌面悬浮窗可展开播放/暂停、切歌或点击“锁”图标开启防误触（此时点击直接穿透悬浮窗，不影响打游戏或聊天；在系统通知栏点击“解锁”即可恢复）。
   - 点击 **【🎵 打开沉浸式全屏歌词视窗】** 可进入全屏沉浸大字滚动模式。
